# 🚀 КОММИТ: Поддержка эмодзи + лимит 200 групп

## 📋 Краткое описание

Реализована полная поддержка эмодзи в постах и увеличен лимит групп с 100 до 200 за сессию.

## 🔧 Ключевые изменения

### 1. Поддержка эмодзи (UTF-8)
**Файл:** `bot/fb_poster.py`
- **Функция `clean_text_for_chromedriver`**: Убрана фильтрация эмодзи, добавлена нормализация Unicode
- **Функция `diagnose_message`**: Добавлен подсчет и позитивная валидация эмодзи
- **JavaScript ввод текста**: Улучшен метод для корректной работы с эмодзи

### 2. Увеличение лимита групп
**Файлы:** `config.ini`, `templates/index.html`, `templates/poster.html`, `bot/fb_poster.py`
- **config.ini**: `max_groups_per_session = 200` (было 20)
- **HTML формы**: `max="200"` и `value="50"` (было max="100", value="20")
- **Конструктор бота**: `self.max_groups = 200` (было 100)

### 3. Веб-интерфейс
**Файл:** `web_app.py`
- **Flask конфигурация**: `JSON_AS_ASCII = False` для UTF-8
- **Валидация сообщений**: Позитивная обратная связь для эмодзи
- **API**: Улучшенная проверка UTF-8 кодировки

### 4. Тестирование
**Файл:** `test_emoji_post.py`
- Полностью переписан с красивым интерфейсом
- Демонстрация новых возможностей
- Подробная диагностика и статистика

## 📊 Технические детали

### Обработка эмодзи
```python
# Старый код (удалял эмодзи)
cleaned_text = ''.join(char for char in text if ord(char) < 0x10000)

# Новый код (сохраняет эмодзи)
cleaned_text = text.replace('\x00', '').replace('\ufeff', '')
cleaned_text = unicodedata.normalize('NFC', cleaned_text)
```

### JavaScript для эмодзи
```javascript
// Улучшенный метод ввода
arguments[0].textContent = text;
const inputEvent = new InputEvent('input', {
    bubbles: true,
    cancelable: true,
    inputType: 'insertText',
    data: text
});
arguments[0].dispatchEvent(inputEvent);
```
