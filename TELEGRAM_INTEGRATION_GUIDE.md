# 🔔 Telegram Integration Guide
## Facebook Group Poster - Уведомления в реальном времени

### 📋 Обзор

Система автопостинга теперь поддерживает **Telegram уведомления** для мониторинга процесса в реальном времени. Вы будете получать уведомления о:

- ⚠️ **Ошибках при постинге** (в момент возникновения)
- ✅ **Успешных постах** (опционально)
- 📊 **Итоговой статистике** по завершению сессии

---

## 🚀 Быстрая настройка

### 1. Создание Telegram бота

1. Откройте Telegram и найдите **@BotFather**
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: "Facebook Poster Bot")
   - Введите username бота (например: "my_fb_poster_bot")
4. **Сохраните токен** - он понадобится для настройки

```
Пример токена: 123456789:ABCdefGHIjklMNOpqrsTUVwxyz
```

### 2. Получение Chat ID

**Для личных сообщений:**
1. Найдите **@userinfobot** в Telegram
2. Отправьте любое сообщение
3. Бот пришлет ваш Chat ID

**Для групповых чатов:**
1. Добавьте вашего бота в группу
2. Добавьте **@userinfobot** в ту же группу
3. Отправьте любое сообщение
4. @userinfobot покажет Chat ID группы

```
Пример Chat ID: -1001234567890 (для групп)
Пример Chat ID: 987654321 (для личных чатов)
```

### 3. Настройка config.ini

Добавьте в ваш `config.ini` секцию `[Telegram]`:

```ini
[Telegram]
# Токен бота от @BotFather
telegram_bot_token = 123456789:ABCdefGHIjklMNOpqrsTUVwxyz

# Chat ID (личный или групповой)
telegram_chat_id = 987654321

# Включить уведомления (true/false)
notifications_enabled = true

# Отправлять только ошибки (true) или все уведомления (false)
errors_only = false
```

## 📱 Типы уведомлений

### ⚠️ Уведомления об ошибках

Отправляются **немедленно** при возникновении проблем:

```
⚠️ Ошибка при постинге:
🔗 Группа: ID: 123456789
❌ Причина: Could not find post creation element
```

**Типичные ошибки:**
- `Could not find post creation element` - не найдена кнопка создания поста
- `Could not find post text area` - не найдено поле ввода текста
- `Text entry failed` - ошибка ввода сообщения
- `Post button click failed` - ошибка нажатия кнопки "Опубликовать"

### ✅ Уведомления об успехе

Отправляются при успешном постинге (если `errors_only = false`):

```
✅ Пост успешно отправлен!
🔗 Группа: ID: 987654321
📊 Прогресс: 15/50
```

### 📊 Итоговая статистика

Отправляется по завершению всей сессии:

```
🎉 Все посты отправлены успешно!

📊 Статистика:
✅ Успешно: 45
❌ Ошибок: 5
📝 Всего обработано: 50
⏱ Время выполнения: 23 мин
```

## ⚙️ Настройки

### Параметры конфигурации

| Параметр | Описание | Значения |
|----------|----------|----------|
| `telegram_bot_token` | Токен бота от @BotFather | Строка |
| `telegram_chat_id` | ID чата для уведомлений | Число |
| `notifications_enabled` | Включить/выключить уведомления | `true`/`false` |
| `errors_only` | Отправлять только ошибки | `true`/`false` |

### Режимы работы

**Полные уведомления** (`errors_only = false`):
- ⚠️ Ошибки при постинге
- ✅ Успешные посты
- 📊 Итоговая статистика

**Только ошибки** (`errors_only = true`):
- ⚠️ Ошибки при постинге
- 📊 Итоговая статистика

## 🔧 Устранение неполадок

### Уведомления не приходят

**Проверьте:**

1. **Токен бота** - правильно ли скопирован из @BotFather
2. **Chat ID** - соответствует ли чату, куда должны приходить уведомления
3. **Бот в группе** - если используете групповой чат, добавлен ли бот
4. **Интернет соединение** - есть ли доступ к api.telegram.org
5. **Настройки** - включены ли уведомления (`notifications_enabled = true`)

### Частые ошибки

**"Telegram notifications enabled but bot_token or chat_id not configured"**
- Проверьте секцию `[Telegram]` в config.ini
- Убедитесь, что токен и chat_id заполнены

**"Failed to send Telegram notification: 401"**
- Неверный токен бота
- Получите новый токен от @BotFather

**"Failed to send Telegram notification: 403"**
- Бот заблокирован пользователем
- Или бот не добавлен в групповой чат

**"Failed to send Telegram notification: 400"**
- Неверный Chat ID
- Проверьте формат Chat ID (число, возможно отрицательное для групп)

### Логи и отладка

Все действия Telegram интеграции логируются:

```
INFO:FacebookGroupPoster:Telegram notification sent successfully
WARNING:FacebookGroupPoster:Failed to send Telegram notification: 403 - Forbidden
```

## 🔒 Безопасность

### Защита токенов

- **Не публикуйте** токен бота в открытых репозиториях
- **Не передавайте** токен третьим лицам
- **Регулярно обновляйте** токен через @BotFather при необходимости

### Рекомендации

- Используйте **отдельного бота** для каждого проекта
- Для команд создайте **групповой чат** с ботом
- **Ограничьте доступ** к config.ini файлу
