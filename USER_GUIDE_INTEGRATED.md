## 📊 **DASHBOARD - ОСНОВНОЙ ИНТЕРФЕЙС**

### 🎛️ **4 основные вкладки:**

#### 📢 **1. Campaigns (Кампании)**
- Просмотр всех ваших кампаний
- ▶️ **Start** - запуск кампании (для статуса 'draft')
- ⏹️ **Stop** - остановка кампании (для статуса 'running')
- 📊 **Real-time прогресс** с progress bar
- 🎨 **Цветовые индикаторы статуса:**
  - 🟦 Running (синий)
  - 🟩 Completed (зеленый)
  - 🟨 Stopped (желтый)
  - 🟥 Failed (красный)
  - ⚫ Draft (серый)

#### ➕ **2. Create Campaign (Создание кампании)**
- **Campaign Name:** Название кампании
- **Message Content:** Текст сообщения для Facebook групп
- **Facebook Group URLs:** Список URL групп (по одному на строку)
- **Max Groups:** Максимальное количество групп
- **Min/Max Delay:** Задержка между постами (секунды)

#### 📊 **3. Analytics (Аналитика)**
- **Total Campaigns:** Общее количество кампаний
- **Messages Sent:** Отправлено сообщений
- **Success Rate:** Процент успешных постов
- **Groups Reached:** Охват групп

#### ⚙️ **4. Settings (Настройки)**
- **Facebook Username:** Ваш логин Facebook
- **Facebook Password:** Пароль Facebook
- **Use Headless Mode:** Скрытый режим браузера (рекомендуется)

## 🚨 **TROUBLESHOOTING**

### ❓ **Частые проблемы:**

#### **1. "Facebook credentials not configured"**
```
Решение: Settings → Заполнить Facebook Username/Password → Save
```

#### **2. "Limit exceeded"**
```
Решение: Уменьшить количество групп или обновить план
```

#### **3. Кампания не запускается**
```
Проверить:
✅ Facebook учетные данные настроены
✅ Статус кампании = 'draft'
✅ Не превышены лимиты плана
✅ Интернет соединение стабильно
```

#### **4. Нет real-time обновлений**
```
Решение: 
✅ Обновить страницу (F5)
✅ Проверить console браузера на ошибки WebSocket
✅ Убедиться что JavaScript включен
```

## 🎯 **BEST PRACTICES**

### 📈 **Для максимальной эффективности:**

1. **Настройка Facebook:**
   - Используйте валидные учетные данные
   - Убедитесь что аккаунт не заблокирован
   - Рекомендуется headless режим

2. **Создание сообщений:**
   - Избегайте спам-контента
   - Используйте персонализированные сообщения
   - Добавляйте эмодзи для привлекательности

3. **Управление группами:**
   - Проверяйте URL групп перед запуском
   - Начинайте с малого количества для тестирования
   - Соблюдайте правила групп

4. **Мониторинг:**
   - Следите за real-time обновлениями
   - Анализируйте причины неудач
   - Корректируйте стратегию на основе результатов
