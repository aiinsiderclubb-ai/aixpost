# 🛡️ РЕШЕНИЕ ПРОБЛЕМ С CAPTCHA И 2FA

## 🚫 Проблема: "CAPTCHA verification required"

Эта ошибка означает, что Facebook требует дополнительную проверку для входа.

## 🔍 Почему это происходит:

1. **Новый IP адрес** - Facebook не узнает ваше местоположение
2. **Новое устройство** - браузер выглядит как новое устройство
3. **Подозрительная активность** - автоматизация была обнаружена
4. **Защита аккаунта** - у вас включена двухфакторная аутентификация

## ✅ Как решить:

### Метод 1: Видимый браузер (Рекомендуется)

1. **Отключите Headless Mode** в форме:
   ```
   ❌ Headless Mode (Faster)
   ```

2. **Запустите процесс заново**:
   - Введите данные для входа
   - Нажмите "Start Fetching"
   - Браузер откроется в видимом режиме

3. **Решите CAPTCHA вручную**:
   - Увидите окно браузера с Facebook
   - Решите CAPTCHA или пройдите 2FA
   - Система автоматически продолжит работу

### Метод 2: Сброс сессии

1. **Нажмите "Reset FB Session"** в Quick Actions
2. **Подтвердите очистку** данных сессии
3. **Попробуйте войти заново** с выключенным headless

### Метод 3: Использование существующей сессии

1. **Войдите в Facebook** обычным способом в браузере
2. **Оставьте браузер открытым**
3. **Попробуйте запустить процесс** с включенной опцией "Use Saved Session"

## 🔧 Технические детали:

### Что происходит при CAPTCHA:
```
1. Система обнаруживает CAPTCHA
2. Делает скриншот (screenshots/captcha_required_*.png)
3. Если headless=false: ждет решения 2 минуты
4. Если headless=true: завершает с ошибкой
5. Проверяет успешность входа каждые 10 секунд
```

### Логи при CAPTCHA:
```
WARNING:fb_group_fetcher:CAPTCHA verification required
INFO:fb_group_fetcher:Browser is visible - please solve CAPTCHA manually and wait...
INFO:fb_group_fetcher:Still waiting for CAPTCHA completion... (1/12)
INFO:fb_group_fetcher:CAPTCHA completed successfully!
```

## 🎯 Пошаговая инструкция:

### 1. Подготовка
- Убедитесь что у вас есть доступ к Facebook аккаунту
- Отключите headless режим
- Приготовьте телефон для 2FA (если включена)

### 2. Запуск процесса
```
1. Заполните форму входа
2. ❌ Уберите галочку "Headless Mode"
3. ✅ Оставьте "Use Saved Session" 
4. ✅ Поставьте "Save Login Data" (если хотите)
5. Нажмите "Start Fetching"
```

### 3. Решение проблем
```
Когда откроется браузер:
1. Дождитесь загрузки Facebook
2. Если появится CAPTCHA - решите его
3. Если требуется код 2FA - введите с телефона
4. Если просят подтвердить устройство - подтвердите
5. НЕ ЗАКРЫВАЙТЕ браузер до завершения процесса
```

### 4. Мониторинг прогресса
```
Следите за:
- WebSocket уведомления в dashboard
- Прогресс бар
- Статус в правой панели
- Логи в терминале
```

## 🚨 Частые ошибки:

### "CAPTCHA not resolved in time"
**Причина**: Не решили CAPTCHA за 2 минуты
**Решение**: Сбросьте сессию и попробуйте снова

### "Login state could not be verified"  
**Причина**: Проблемы с куками или сессией
**Решение**: Используйте "Reset FB Session"

### "Two-factor authentication required"
**Причина**: У вас включена 2FA
**Решение**: Введите код с телефона в браузере

## 💡 Лучшие практики:

### Для избежания CAPTCHA:
1. **Используйте стабильный интернет**
2. **Не меняйте IP часто** 
3. **Входите через обычный браузер** сначала
4. **Подтвердите устройство** в настройках Facebook

### Для стабильной работы:
1. **Сохраняйте сессии** (Use Saved Session = ✅)
2. **Не запускайте часто** (Facebook может заблокировать)
3. **Используйте надежные пароли**
4. **Включите сохранение данных** для будущих запусков

## 🎉 После успешного входа:

Система автоматически:
- ✅ Сохранит сессию для будущего использования
- ✅ Начнет поиск групп
- ✅ Покажет real-time прогресс
- ✅ Сохранит найденные группы в JSON файл
