## 🔗 **API Endpoints (все работают!):**

### 📋 Управление шаблонами:
```bash
# Список всех шаблонов
GET /api/templates/list

# Удаление одного шаблона
POST /api/templates/delete
{"template_index": 5}

# Массовое удаление шаблонов
POST /api/templates/delete_multiple  
{"template_indices": [1, 3, 5]}

# Добавление нового шаблона
POST /api/templates/add
{"template": "Новый шаблон с {{city}} и {{emotion}}"}
```

### 📊 Статистика и предпросмотр:
```bash
# Статистика системы
GET /api/templates/stats

# Генерация сообщения
GET /api/templates/generate?template_index=2

# Предварительный просмотр
GET /api/templates/preview

# Доступные переменные
GET /api/templates/variables
```

## 🎯 **Как использовать:**

### 📝 **1. Управление шаблонами:**
1. Откройте http://localhost:8080/templates
2. **Просматривайте** существующие шаблоны с preview
3. **Добавляйте** новые шаблоны с переменными
4. **Удаляйте** ненужные шаблоны (одиночно или массово)

### 🎯 **2. Выбор шаблонов для рассылки:**
1. **Выберите нужные шаблоны** (кликните по карточкам)
2. Нажмите **"Preview Selected"** для просмотра
3. Нажмите **"Post with Selected"** для рассылки
4. Система **автоматически перенаправит** в Poster с выбранными шаблонами

### 🚀 **3. Запуск рассылки:**
1. В Poster автоматически включится **"Use Templates"**
2. Появится уведомление о количестве выбранных шаблонов
3. Запускайте постинг - **каждая группа получит уникальное сообщение**!
