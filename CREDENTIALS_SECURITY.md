# 🔐 БЕЗОПАСНОСТЬ УЧЕТНЫХ ДАННЫХ

## 🎯 Проблема, которую решаем

**До обновления**: Пользователю приходилось каждый раз вводить логин и пароль Facebook заново.

**После обновления**: Система может безопасно сохранять учетные данные и автоматически загружать их.

## 🔒 Система шифрования

### Алгоритм защиты
- **Библиотека**: `cryptography` (Fernet encryption)
- **Алгоритм**: AES 128-bit в режиме CBC
- **Ключ**: Уникальный для каждой установки
- **Файлы**: 
  - `encryption.key` - ключ шифрования
  - `saved_credentials.enc` - зашифрованные данные

### Что шифруется
```json
{
    "username": "your_facebook_email@gmail.com",
    "password": "your_secure_password",
    "saved_at": "2024-01-20T15:30:00"
}
```

## 🚀 Как использовать

### 1. Сохранение данных
1. Введите логин и пароль в форме
2. ✅ Поставьте галочку **"💾 Save Login Data"**
3. Нажмите **"Start Fetching"**
4. Данные будут зашифрованы и сохранены

### 2. Загрузка сохраненных данных
1. Нажмите кнопку **"🔽 Load Saved Data"**
2. Поля автоматически заполнятся
3. Можете сразу запускать процесс

### 3. Управление данными
- **Просмотр**: Видите какой аккаунт сохранен
- **Удаление**: Кнопка "🗑️ Delete" для полного удаления

## 🛡️ Безопасность

### ✅ Что защищено
- Данные шифруются локально на вашем компьютере
- Ключ шифрования уникален для каждой установки
- Пароли никогда не передаются по сети в открытом виде
- Сервер НЕ сохраняет ваши данные

### ⚠️ Важные моменты
- Файлы шифрования хранятся локально
- При удалении папки проекта - данные теряются
- Бэкап ключа шифрования - ваша ответственность

## 🔧 API Endpoints

### Получить информацию о сохраненных данных
```http
GET /api/credentials
```

Ответ:
```json
{
    "has_saved_credentials": true,
    "username": "your_email@gmail.com",
    "saved_at": "2024-01-20T15:30:00",
    "password_length": 12
}
```

### Сохранить учетные данные
```http
POST /api/credentials
Content-Type: application/json

{
    "username": "your_email@gmail.com",
    "password": "your_password"
}
```

### Загрузить учетные данные
```http
POST /api/credentials/load
```

Ответ:
```json
{
    "username": "your_email@gmail.com",
    "password": "your_password"
}
```

### Удалить учетные данные
```http
DELETE /api/credentials
```

## 🚨 Устранение проблем

### Ошибка "No saved credentials found"
**Причина**: Данные не были сохранены или файлы удалены
**Решение**: Введите данные заново и сохраните

### Ошибка "Failed to save credentials"
**Причина**: Проблемы с правами записи или шифрованием
**Решение**: Проверьте права на папку проекта

### Ошибка "Failed to load credentials"
**Причина**: Поврежденные файлы шифрования
**Решение**: Удалите файлы `*.enc` и `*.key`, сохраните заново
