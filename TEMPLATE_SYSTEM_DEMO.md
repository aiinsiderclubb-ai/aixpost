# 🧠 Система Вариативных Шаблонов - Демонстрация

## 📋 Обзор системы

Система вариативных шаблонов позволяет создавать уникальные сообщения для каждой группы, избегая повторов и повышая эффективность рассылки.

### ✨ Ключевые возможности:
- **10 готовых шаблонов** с динамическими переменными
- **13,720,000+ уникальных комбинаций** сообщений
- **Автоматическая подстановка** переменных
- **Режимы работы**: случайный выбор или последовательный
- **Telegram уведомления** с информацией о шаблонах
- **Web интерфейс** для управления

---

## 🎯 Примеры сгенерированных сообщений

### Шаблон #1: Приветствие
**Оригинал:** `Привет! Мы работаем в {{city}} каждый {{day}} — {{action}}! {{emotion}}`

**Варианты:**
- Привет! Мы работаем в Цюрих каждый понедельник — заходи! ✨
- Привет! Мы работаем в Женева каждый среда — присоединяйся! 💪
- Привет! Мы работаем в Берн каждый пятница — звони! 🔥

### Шаблон #6: Специальное предложение
**Оригинал:** `🎯 Специальное предложение в {{city}}! {{urgency}} — {{call_to_action}}`

**Варианты:**
- 🎯 Специальное предложение в Базель! только сегодня — Звони сейчас!
- 🎯 Специальное предложение в Люцерн! ограниченное время — Не упусти шанс!
- 🎯 Специальное предложение в Лозанна! последние дни — Успей записаться!

### Шаблон #3: Новая неделя
**Оригинал:** `💡 В {{city}} начинается новая неделя с {{benefit}}. Ждём в {{day}}!`

**Варианты:**
- 💡 В Женева начинается новая неделя с скидки. Ждём в четверг!
- 💡 В Винтертур начинается новая неделя с специальные предложения. Ждём в вторник!
- 💡 В Цюрих начинается новая неделя с подарки. Ждём в суббота!

## 🔧 Технические детали

### Переменные системы:
- **city**: 7 швейцарских городов (Цюрих, Берн, Люцерн, Женева, Базель, Лозанна, Винтертур)
- **day**: 7 дней недели
- **time**: 5 временных периодов (утром, днем, вечером, после обеда, до обеда)
- **action**: 4 призыва к действию (заходи, присоединяйся, звони, приходи)
- **emotion**: 4 эмодзи (✨, 💪, 🔥, 🎉)
- **urgency**: 4 варианта срочности
- **call_to_action**: 4 призыва к действию
- **benefit**: 4 типа выгод
- **mood**: 4 настроения
- **service**: 4 типа услуг

### Статистика:
- **Всего шаблонов**: 10
- **Всего переменных**: 10 типов
- **Всего вариантов**: 53 значения
- **Возможных комбинаций**: 13,720,000+

## 🚀 Использование

### 1. Через Web интерфейс:
1. Откройте http://localhost:8080
2. Включите переключатель "Use Templates"
3. Выберите режим: "Random" или "Sequential"
4. Запустите постинг

### 2. Через API:
```bash
# Получить статистику
curl http://localhost:8080/api/templates/stats

# Сгенерировать сообщение
curl http://localhost:8080/api/templates/generate

# Предварительный просмотр
curl http://localhost:8080/api/templates/preview
```

### 3. Через конфигурацию:
```ini
[Templates]
use_templates = true
template_mode = random
log_template_usage = true
```
