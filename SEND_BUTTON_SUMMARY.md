# 🎯 Кнопка "Отправить" - ИСПРАВЛЕНО!

## 🔍 Проблема
На скриншотах пользователя видно, что кнопка в диалоге имеет текст **"Отправить"**, а не "Опубликовать" или "Поделиться", как предполагалось.

## ✅ Решение
Добавлены селекторы для поиска кнопки **"Отправить"** с высшим приоритетом:

### Обновленные селекторы (первые 3):
```xpath
1. "//div[@role='dialog']//div[@role='button'][.//span[contains(text(), 'Отправить')]]"
2. "//div[@role='button' and contains(@aria-label, 'Отправить')]" 
3. "//span[contains(text(), 'Отправить')]//ancestor::div[@role='button'][1]"
```

### JavaScript fallback:
```javascript
if (text.includes('Отправить') || ...)
```
